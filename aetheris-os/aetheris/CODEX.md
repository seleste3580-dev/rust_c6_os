# CODEX.md

This project was generated by `esp-generate` for Espressif MCUs and then grown into **Aetheris OS**,
a phone-style firmware shell for the ESP32-C6 (Seleste Technologies). See `README.md` for wiring, apps and usage.

## Project-specific notes

- Target chip: `esp32c6`; keep dependencies, HAL features, and examples compatible with this chip.
- This is a `#![no_std]` / `#![no_main]` project. Avoid `std`; use `core`, `alloc` and embedded-friendly crates.
- `alloc` is enabled. The heap is created in `src/bin/main.rs` with `esp_alloc::heap_allocator!(size: 150 * 1024)`; Wi-Fi needs ~55 KB of it.
- `.cargo/config.toml` contains the target, the runner (`espflash flash --monitor --chip esp32c6 --partition-table partitions.csv`),
  `ESP_LOG=info` and `build-std`. `cargo run --release` flashes through the board's USB serial/JTAG connection.
- If flashing fails, check bootloader mode (hold BOOT, tap RESET), serial-port permissions, the selected port, and the `--chip` value.
- Flash layout is defined in `partitions.csv` (two 3 MB OTA slots + `otadata` + a 56 KB `storage` partition used for settings).
  OTA and persistent settings only work when the board was flashed with this table (the runner does that).

## Architecture rules (read before editing)

- **Two halves.** Everything outside `src/hw/` and `src/bin/main.rs` is hardware-independent (`os`, `apps`, `ui`, `settings`, `sound`, ...).
  `hw` is compiled only for `target_os = "none"`. Keep the split: it lets the UI be unit-tested/simulated on a PC (`../aetheris-sim`).
- **Apps never touch hardware.** An app implements `apps::App` (`key`, `tick`, `draw`, optional `owns_star`, `on_exit`, `keep_awake`)
  and talks to the world only through `Sys` (`sys.snd()`, `sys.tone()`, `sys.play()`, `sys.led_pulse()`, `sys.wifi_cmd()`, `sys.save()`).
  `Sys` collects `Effect`s; `src/bin/main.rs` applies them to the real peripherals each frame.
- **Two screens.** `draw(a, b, sys)`: `a` = main OLED (yellow title band = rows 0-15, use `gfx::title`), `b` = secondary OLED.
  Both are 128x64 `Fb` framebuffers in SSD1306 page layout. Hints at the bottom of `a` must be <= 25 chars (`gfx::hint` clips).
- **Registry.** Apps are registered in the `apps! { ... }` table in `src/apps/mod.rs` (index = menu order = icon source in `src/icons.rs`).
- **Never block for long in the UI loop.** OLED flushes are page-wise and yield (`embassy_futures::yield_now`).
  Flash writes happen in `storage_task` (debounced) or under the `FLASH` mutex (OTA only).
- **Keys.** Matrix scan -> `KeyScanner` -> `KeyEvent{key, kind: Press|Repeat|Long|Release}`. Use `ev.nav()` for arrows, `ev.press()` for single actions.
  Holding `*` goes Home unless the app returns `owns_star() == true`.
- **Settings** live in `settings::Settings` (binary codec + CRC32, passwords salted SHA-256). Change the codec => bump `MAGIC`.
- **Do not store secrets in logs.** Wi-Fi/OS passwords must never be printed with `log::*`.

## Hardware map (GPIO)

| Function | GPIO |
|---|---|
| OLED A SDA / SCL (hardware I2C0) | 6 / 7 |
| OLED B SDA / SCL (bit-banged I2C) | 20 / 21 |
| Keypad rows R1-R4 | 0, 1, 2, 3 |
| Keypad cols C1-C4 | 10, 11, 18, 19 |
| IR sensor OUT | 4 |
| Green LED | 22 |
| Passive buzzer | 23 |

Avoid GPIO5, 8, 9, 15 (strapping), 12/13 (USB), 16/17 (UART0), 24-30 (flash).
